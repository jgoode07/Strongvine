# Strongvine Visual Communications

**Author: Joseph Goode**

A design-first creative agency website built from the ground up using semantic HTML, modern CSS, and lightweight JavaScript interactions. Strongvine focuses on bold typography, motion, spatial balance, and clean visual hierarchy while avoiding bloated frameworks and template-driven design.

The project was developed as a high-fidelity front-end build based on supplied PSD files and collaborative creative direction.

---

## Overview

Strongvine is a visually driven landing page experience designed to showcase a premium creative agency brand. The build emphasizes:

- Precision layout structure
- Typography-driven design
- Responsive spacing systems
- Subtle motion and interaction design
- Accessibility-conscious implementation
- Performance-focused front-end architecture

The project intentionally avoids unnecessary dependencies in favour of maintainable, readable code and scalable naming conventions.

---

## Features

- Semantic HTML5 structure
- Fully custom CSS architecture
- BEM-inspired naming conventions
- Responsive typography using `clamp()`
- CSS variable token system
- Section-based spacing system
- Animated UI interactions
- Motion accessibility support via `prefers-reduced-motion`
- Responsive full-width section breakouts
- Interactive Results section toggle state
- Typing animation with animated cursor effect
- Smooth scrolling integration using Lenis
- Custom animated footer microinteraction
- Lightweight vanilla JavaScript enhancements

## Design Approach

### Typography & Spatial Design

The layout relies heavily on proportion, whitespace, alignment, and controlled scaling to create a premium visual rhythm across large desktop layouts and responsive breakpoints.

### Motion Design

Animations are intentionally subtle and purposeful rather than decorative. Interactive elements such as icon movement, typing effects, smooth scrolling behaviour, and UI toggles were designed to reinforce brand personality without overwhelming the experience.

### Maintainability

The CSS architecture is organized into clearly separated sections with reusable tokens and consistent naming patterns to improve scalability and long-term maintainability.

## Accessibility Considerations

Strongvine includes several accessibility-focused implementation details, including:

- Semantic heading structure
- Reduced motion support
- Responsive scaling

- Keyboard-friendly interactive elements
